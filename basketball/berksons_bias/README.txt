There are 7 files in this folder:

1. SCORE_Berksons.Rmd - this is an RMarkdown file, structured as an interactive `learnr` tutorial - that is our main module file. There is also another folder titled "images" that contains two image files rendered in the RMarkdown module.

2. cbb_join.csv - this is our main data file containing joined and cleaned college basketball and NBA draft data. This is the data analyzed in the tutorial module.

3. cbb_join_Data_Dictionary.csv - this is a data dictionary file for cbb_join.csv.

4. README.txt - this readme file.

5. Learning_Objectives_Basketball_Berksons.docx - this is a list of learning objectives associated with the module.

6. CollegeBasketballPlayers2009-2021.csv - the original raw data containing all men's college basketball player statistics from 2009-2021.

7. DraftedPlayers2009-2021.xlsx - the original raw data containing NBA draft data from 2009-2021.
