SCORE Preprint Module Repository

The SCORE Network Module Repository enables you to search for modules by either sport or by statistics and data science topic.

Please note that the modules listed in this repository have not yet completed the required pedagogical and industry peer reviews to become a published module on the SCORE Network.

Instructors and students are still welcome to use these preprints. Additionally, if you use them and have feedback for the authors, please contact scorenetworkorg@gmail.com.
